# Coder Commander

Современный двухпанельный файловый менеджер для разработчиков.

## 📋 О проекте

Coder Commander — это профессиональный файловый менеджер с открытым исходным кодом, созданный специально для разработчиков. Приложение сочетает классический двухпанельный интерфейс с современными возможностями: встроенный редактор кода с подсветкой синтаксиса, просмотрщик файлов с поддержкой изображений, операции с архивами и многое другое.

## ✨ Основные возможности

###  Управление файлами
- **Двухпанельный интерфейс** — классический подход с двумя независимыми панелями
- **Навигация** — быстрый переход по директориям, история навигации
- **Операции с файлами** — копирование, перемещение, удаление, переименование
- **Массовое переименование** — гибкое переименование файлов по шаблону
- **Синхронизация директорий** — сравнение и синхронизация папок
- **Закладки** — быстрый доступ к часто используемым директориям

### 📝 Встроенный редактор кода
- **Подсветка синтаксиса** для 25+ языков программирования:
  - C, C++, C#, Java, JavaScript, TypeScript
  - Python, Ruby, Go, Rust, Swift, Kotlin
  - HTML, XML, CSS, JSON, SQL, Markdown
  - PHP, Shell, PowerShell, YAML, INI, Dockerfile, Makefile
- **Множественные вкладки** — одновременная работа с несколькими файлами
- **Тулбар** — быстрый доступ к основным операциям
- **Поиск и замена** — поиск текста в файле
- **Перенос строк** — настройка отображения длинных строк
- **Статус-бар** — информация о файле, позиции курсора, кодировке

### 👁️ Просмотрщик файлов
- **Текстовый режим** — просмотр текстовых файлов до 16 МБ
- **Hex-режим** — просмотр файлов в шестнадцатеричном формате
- **Режим изображений** — поддержка JPG, PNG, GIF, BMP, ICO, SVG, WebP, TIFF
- **Масштабирование** — zoom от 10% до 500% для изображений
- **Навигация** — переключение между файлами без закрытия просмотрщика

###  Работа с архивами
- **Поддержка форматов** — ZIP архивы
- **Просмотр содержимого** — навигация внутри архива как по обычной папке
- **Извлечение файлов** — распаковка выбранных файлов или всего архива
- **Создание архивов** — упаковка файлов в ZIP

### 🔍 Поиск и сравнение
- **Поиск файлов** — поиск по имени и содержимому
- **Сравнение файлов** — текстовое сравнение двух файлов
- **Контрольные суммы** — вычисление хешей файлов (MD5, SHA1, SHA256, SHA512)

### 🎨 Интерфейс
- **Тёмная и светлая темы** — VSCode-style оформление
- **Настраиваемый интерфейс** — скрытие/показ элементов интерфейса
- **Горячие клавиши** — полная поддержка клавиатурных сокращений
- **Локализация** — русский и английский языки

## 🚀 Установка

### Системные требования
- **ОС**: Windows 10/11 (x64)
- **.NET**: .NET 8.0 Runtime или SDK
- **RAM**: 512 МБ минимум
- **Диск**: 50 МБ свободного места

### Установка из исходного кода

1. **Клонируйте репозиторий**:
```bash
git clone https://github.com/romanborodin77/coder-commander.git
cd coder-commander
```

2. **Восстановите зависимости**:
```bash
dotnet restore
```

3. **Соберите проект**:
```bash
dotnet build --configuration Release
```

4. **Запустите приложение**:
```bash
dotnet run --project CoderCommander.csproj
```

Или запустите собранный исполняемый файл:
```bash
.\bin\Release\net8.0-windows\CoderCommander.exe
```

### Публикация standalone версии

Для создания независимой версии без необходимости установки .NET:

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Собранный файл будет находиться в `bin\Release\net8.0-windows\win-x64\publish\`.

## 📖 Использование

### Горячие клавиши

#### Основные операции
| Клавиша | Действие |
|---------|----------|
| `F3` | Просмотр файла |
| `F4` | Редактирование файла |
| `F5` | Копировать |
| `F6` | Переместить |
| `F7` | Создать папку |
| `F8` | Удалить |
| `Shift+F8` | Безвозвратное удаление |
| `F9` | Терминал |
| `F10` | Выход |

#### Навигация
| Клавиша | Действие |
|---------|----------|
| `←` / `→` | Переключение между панелями |
| `↑` / `↓` | Перемещение по списку файлов |
| `Enter` | Открыть файл/папку |
| `Backspace` | Переход на уровень вверх |
| `Alt+F1` / `Alt+F2` | Смена диска левой/правой панели |

#### Выделение
| Клавиша | Действие |
|---------|----------|
| `Insert` | Выделить/снять выделение с файла |
| `+` (NumPad) | Инвертировать выделение |
| `*` (NumPad) | Выделить всё |
| `Ctrl+A` | Выделить все файлы |

#### Редактор
| Клавиша | Действие |
|---------|----------|
| `Ctrl+S` | Сохранить файл |
| `Ctrl+N` | Новая вкладка |
| `Ctrl+O` | Открыть файл |
| `Ctrl+F` | Найти |
| `Ctrl+W` | Закрыть вкладку |
| `Ctrl+Z` | Отменить |
| `Ctrl+Y` | Повторить |

#### Просмотрщик
| Клавиша | Действие |
|---------|----------|
| `Escape` | Закрыть просмотрщик |
| `←` / `→` | Предыдущий/следующий файл |
| `F5` | Обновить |
| `Ctrl++` | Увеличить масштаб |
| `Ctrl+-` | Уменьшить масштаб |

### Работа с архивами

Для просмотра содержимого ZIP-архива просто откройте его как обычную папку. Навигация внутри архива работает так же, как с обычными директориями.

Для создания архива:
1. Выделите файлы для упаковки
2. Нажмите `Alt+F5` или выберите **Файл → Упаковать**
3. Укажите имя архива и параметры сжатия

### Синхронизация директорий

1. Откройте **Команды → Синхронизация каталогов**
2. Выберите левую и правую директории
3. Нажмите **Сравнить**
4. Выберите файлы для копирования и направление синхронизации

## 🛠️ Технологии

- **Платформа**: .NET 8.0
- **UI фреймворк**: Windows Forms (WinForms)
- **Архитектура**: MVVM (Model-View-ViewModel)
- **Паттерны**: Command Pattern для обработки команд
- **Локализация**: Собственная система локализации с .lng файлами
- **Темы**: VSCode Dark+ и Light+ цветовые схемы
