# Coder Commander

**Coder Commander** — двухпанельный файловый менеджер для разработчиков на Windows: .NET 8
WinForms, с встроенным редактором кода, универсальным просмотрщиком, поддержкой архивов и
удалённых подключений, терминалом и синхронизацией каталогов.

---

## Возможности

- **Двухпанельный интерфейс** с настраиваемой сортировкой, скрытыми файлами, плоским видом,
  drive-баром и подсветкой статуса git (изменено/добавлено/удалено/untracked/конфликт) прямо в
  списке файлов
- **Файловые операции**: копирование, перемещение, удаление (в Корзину или безвозвратное
  затирание), переименование, массовое переименование по шаблону, создание каталогов
- **Единая виртуальная файловая система** — локальный диск, архив или удалённое подключение
  открываются в панели одинаково; копирование/перемещение работает между любой их комбинацией
- **Архивы**: просмотр/распаковка/упаковка ZIP, TAR, TAR.GZ, 7z, RAR, TAR.BZ2, TAR.XZ
  (ZIP/TAR/TAR.GZ/TAR.BZ2 — с записью, 7z/RAR/TAR.XZ — только чтение), переименование записей
  прямо внутри архива, распаковка запароленных 7z/RAR по запросу пароля
- **Удалённые подключения**: WebDAV, SFTP, FTP/FTPS, SMB — с сохранёнными профилями и паролями,
  зашифрованными через DPAPI
- **MTP-устройства** — доступ к Android-телефонам и камерам через Windows Portable Devices прямо
  в панели, как к обычной папке
- **Встроенный редактор кода** (F4) с подсветкой синтаксиса 25+ языков, переносом длинных строк
  (word wrap), вкладками и поиском
- **Универсальный просмотрщик** (F3): текст (с определением кодировки), ASCII, бинарный, hex,
  изображения, CSV/TSV, Markdown, HTML, PDF, аудио/видео, а также Word/Excel/PowerPoint и
  OpenDocument Text/Calc/Impress — без сторонних приложений
- **Встроенный терминал** (F9) — cmd, PowerShell, pwsh, Git Bash, WSL — с вкладками и
  настраиваемыми хоткеями
- **Поиск по имени и содержимому** файлов (Alt+F7), включая файлы внутри архивов и на
  подключениях
- **Сравнение файлов** (Differ) и **синхронизация каталогов** (SyncDirs) между любыми двумя
  источниками
- **Контрольные суммы** файлов, дерево каталогов, закладки, диалог свойств с массовым изменением
  атрибутов (изменение времени — только для одиночного выбора)
- **Тема оформления** — VSCode Dark+/Light+ палитра, применяется живьём без перезапуска
- **Локализация** — русский и английский

## Требования

- Windows 10/11
- .NET 8.0 SDK (для сборки) или .NET 8.0 Desktop Runtime (для запуска собранного `.exe`)

## Сборка и запуск

```bash
git clone https://github.com/romanborodin77/coder-commander.git
cd coder-commander
dotnet restore
dotnet build --configuration Release
```

Запуск из исходников:

```bash
dotnet run --project CoderCommander.csproj
```

Или напрямую собранный исполняемый файл:

```bash
.\bin\Release\net8.0-windows\CoderCommander.exe
```

Автономная сборка одним файлом (без установленного .NET на целевой машине):

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Артефакт окажется в `bin/Release/net8.0-windows/win-x64/publish/`.

## Горячие клавиши

| Клавиша | Действие | Клавиша | Действие |
|---|---|---|---|
| F3 | Просмотр файла | F8 / Shift+F8 | Удаление / безвозвратное затирание |
| F4 | Редактирование | F9 | Терминал |
| F5 | Копировать | F10 / Alt+X | Выход |
| F6 | Переместить | Alt+F7 | Поиск файлов |
| F2 | Переименовать | Alt+F5 / Alt+F9 | Упаковать / распаковать |
| F7 | Создать каталог | Ctrl+M | Массовое переименование |
| Shift+F4 | Новый файл | Ctrl+P | Плоский вид (рекурсивный список) |
| Ctrl+A / Ctrl+D | Выделить всё / снять выделение | Ctrl+U | Поменять панели местами |
| Ctrl+G | Перейти в каталог | Ctrl+. | Показать/скрыть скрытые файлы |
| Ctrl+\ / Ctrl+Home | Корень диска / домашний каталог | Alt+Enter | Свойства |
| Ctrl+R / Ctrl+Shift+R | Обновить / обновить диски | Ctrl+Alt+Space | Размер папки |
| Ctrl+1 / Ctrl+2 | Тёмная / светлая тема | Ctrl+Shift+T / W | Новая / закрыть вкладку терминала |
| Num+ | Инвертировать выделение | Ctrl+Num+ / Ctrl+Num− | Выделить / снять группу по маске |

Остальные действия (закладки, подключения, дерево каталогов, контрольные суммы, синхронизация,
сравнение) доступны через меню.

## Структура репозитория

```
Commands/       Диспетчеризация команд и хоткеев
FileSystem/     Абстракция файловой системы (локальная / архивы / удалённые подключения)
Archives/       Форматы архивов (ZIP, TAR-семейство, 7z, RAR)
Operations/     Очередь файловых операций (копирование/перемещение/удаление/упаковка)
Services/       Темы, настройки, локализация, поиск, git-статус
Viewers/        Форматы просмотрщика F3
ViewModels/      MVVM-слой (MainViewModel, PanelViewModel)
Views/          Главное окно и панель
WinForms/       Диалоги и кастомные контролы
Terminal/       Встроенный терминал (ConPTY)
lang/           Файлы локализации (en/ru)
UiTests/        Автоматизированные UI-тесты (FlaUI + NUnit)
```

Подробное описание архитектуры — в `AGENTS.md`.

## Разработка

1. Форкните репозиторий.
2. Создайте ветку: `git checkout -b feat/имя-фичи`.
3. `dotnet build` должен проходить без ошибок перед коммитом.
4. Откройте PR с описанием изменений.
