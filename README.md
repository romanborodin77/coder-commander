# Coder Commander

**Coder Commander** — открытый двухпанельный файловый менеджер для разработчиков, реализованный на C# (.NET). Проект предоставляет удобный интерфейс для навигации по проектам, работы с файлами, быстрого просмотра и редактирования кода, а также интеграции с полезными инструментами разработки.

---

## Основные возможности

- Двухпанельный интерфейс и быстрая навигация по директориям
- Работа с файлами: копирование, перемещение, удаление, переименование
- Множественное/массовое переименование по шаблонам
- Встроенный редактор кода с подсветкой синтаксиса и вкладками
- Просмотрщик (текст, hex, изображения)
- Работа с ZIP-архивами (просмотр/извлечение/упаковка)
- Поиск по имени и содержимому файлов
- Сравнение файлов и синхронизация директорий
- Горячие клавиши для всех основных операций
- Локализация (русский / английский)

## Быстрый старт (для разработчиков)

Требования:

- .NET 8.0 SDK или Runtime
- Windows 10/11 (текущая реализация — WinForms)

Клонирование и сборка:

```bash
git clone https://github.com/romanborodin77/coder-commander.git
cd coder-commander
dotnet restore
dotnet build --configuration Release
```

Запуск проекта (пример для локальной разработки):

```bash
dotnet run --project src/CoderCommander/CoderCommander.csproj
```

Сборка самодостаточного исполняемого файла для Windows x64:

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Сборочный артефакт окажется в каталоге `bin/Release/net8.0-windows/<runtime>/publish/`.

## Использование

1. Откройте приложение и укажите папку проекта или корневую директорию.
2. Перемещайтесь между панелями, открывайте файлы клавишей Enter.
3. Для просмотра используйте F3, для редактирования — F4.
4. Горячие клавиши и бинды можно настраивать в настройках приложения.

Подробный список горячих клавиш находится в разделе "Features" внутри приложения (или в старом README-разделе таблиц).
